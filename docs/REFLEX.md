# 可选预判与资源准备实验

2026-09-22 · 设计已评审，尚未实现 · P2、默认关闭 · 契约仍为 v0.1.0。

决策依据：[ADR 0004](ADR/0004-speculative-preparation-is-optional.md)。本页取代原提案中预判预热部分的工程建议，不采纳其影子执行路径。

## 采纳与修正

| 原提案 | 本项目处理 |
|---|---|
| 概率判断与控制规则分离 | 采纳；授权、租约、去重、停止仍由确定性代码和硬件负责 |
| Gateway 可选 sidecar，模型中立 | 采纳设计；无此组件也必须完整工作 |
| 79ms、200 倍速度、1/400 成本 | 不作为项目指标；不同模型、硬件和基准的结果不能混为现场云调用延迟 |
| 预热 Agent 会话池、预载影子 | 不采纳；当前没有相应接口或授权，已建立 WSS 连接也不等于执行 session |
| NFC 场信号、靠近、眼镜佩戴 | 先确认实际传感器和驱动事件；两台 Passport 的被动 NFC 不提供读卡器场检测 |
| 入住越多预测越准 | 不采纳为事实；没有训练、反馈更新和独立评估就不会自动学习 |
| 确定性规则“100%可靠” | 改为必须验证的约束；实现仍可能有缺陷，物理停止需实测 |
| 云 API 运行于本地 | 本地仅是调用方；推理在提供方，必须计入网络延迟 |

## 外部事实核验

2026-09-22 查阅 [TypeSafe 官方发布](https://typesafe.ai/blog/introducing-system-one-models-and-jev)：Jev 面向快速结构化决策，发布时处于 early access。[OpenRouter 模型目录](https://openrouter.ai/models?fmt=table) 列有 Jev。以上仅证明产品定位和目录信息，不证明本队账号有权限、现场连通、费用额度或实测时延。

实现前由负责人确认官方 API 请求/响应、模型版本、凭证与额度，做最小调用。第三方复现模型与 Jev 服务分开记录，不移用彼此指标。此次未调用付费模型，也未验证原提案所有人物、复现、平台和真机能力说法；这些不写入项目承诺。

## 开工门槛

1. P0 真实输入、远端 Agent、两块板、记忆与交接已通过验收。
2. 测量确认存在可提前准备的 Gateway 本地资源；WSS 常驻本身不需要预测。
3. 找到早于明确输入的实际信号。只有按键或已读出的 NFC 地址时，优先直接处理，无须模型。
4. 确定准备操作不会触发设备 I/O、不读取私人数据、不占用 session；给出耗时、内存和调用预算。

任一项不成立，保持关闭。眼镜、多壳自动路由和传感器采购不因本实验加入本次范围。

## 内部流程（不是公共消息）

信号采集 → 本地限流 → 异步预测 → 验证结果及当前状态 → 白名单资源准备 → 到期回收。

- 初始实验参数：每 Gateway 最多一个请求在途，同一信号源 10 秒内一次；请求超时 500ms；结果有效期最多 3 秒。均需实测调整，不是性能承诺。
- 输出只接受有限数值 p∈[0,1]；初始阈值 0.8 待标定。NaN、越界、缺字段、未知动作和返回文本均视为无建议；不接受模型指定代码、URL、工具或 agent_id。
- 结果到达时重新确认壳 IDLE、物理就绪、连接代次与采集时一致。进入 ACTIVE/FAULT/ESTOP、失联或过期时丢弃；重新连上也不使用旧结果。
- 请求在独立异步任务/进程中执行，不占用心跳、停止和命令处理线程。准备资源容量有界、可回收；禁止凭模型输出开启设备句柄。
- 失败不重试当前事件；连续 3 次失败暂停模型调用 60 秒。达到负责人预设的费用上限时关闭。误判也可能浪费资源，不称“完全无害”。
- 无模型基线是关闭预判或基于已有合法事件的简单准备规则。公网断开不可能预热远端 Agent；回到既有连接恢复流程。

## 评估与退出

比较三组：不预热、确定性预热、模型预判。使用同一资源、相近网络和交互样本，区分首次与重复请求；记录预测发起到返回时间、资源准备耗时、明确输入到 ACTIVE、动作开始与完成时间，以及调用数、费用、误触发和失败。

命中定义：预测为真后 3 秒内同一壳发生明确召唤请求；一个请求最多匹配一次预测。精确率为命中数/正预测数，召回率为被提前命中的请求数/全部真实请求数；分母为零记 N/A。不能只展示命中样本的延迟，需同时报告全量样本的 p50/p95 与数量。

只有全量延迟获得有意义改善、尾延迟和主链稳定性未恶化、费用可接受，才保留。固定模型加缓存不等于训练，更不等于识别了具体个人。

新增组件实现后，单独测试：超时、晚到、重复、异常输出、预算耗尽、状态改变和断网；均不得产生 session 或执行器动作，不得拖延心跳和停止。现有检查仍须通过：

```sh
python tools/validate_contract.py
python tools/summon_device_ref.py --selftest
```
