这里保存可复用的工程规则、设计决策与经脱敏的验证结论。设备执行的运行时经验仍进入云端经验库；两者不是同一份数据，不自动将私人运行日志公开到 GitHub。

## 2026-09-22：手机配网、铭牌和返回

来源：项目发起人的明确产品要求。状态：**已纳入开发 Skill，待具体目标实现与实物验收**。不是已经验证的板级经验。

| 规则 | 要解决的问题 | 实现与验收依据 |
|---|---|---|
| Wi-Fi SoftAP + 本地配置页面 | 刷完固件仍需改源码才能换网络 | 手机连设备热点，配置 Wi-Fi 与 Agent 铭牌，页面离线可用 |
| 独立显示 Wi-Fi 与 Agent 状态 | 联网成功被误认为 Agent 已接入 | 区分网络、身份解析、离线、授权与会话 |
| 所有非根页可返回 | 用户进入配置页面后无法退出 | 页面返回、根页行为、未保存内容处理 |
| 双击确认等于返回 | 按键少的设备没有统一返回方式 | 延迟单击提交，双击只返回，非阻塞消抖 |
| 保留可用配置并能重新配网 | 错误密码或换路由器导致设备失联 | 待验证配置、原子保存、有界失败回退 |
| 铭牌不等于控制密钥 | 公开名称被误当作设备授权 | 唯一身份解析、设备授权、切换前停止 |

规则正文只维护在 [固件交互要求](../skills/summon-device-onboarding/references/firmware-ux.md)，Skill 包及在线入口包含相同内容。

当前缺口：没有目标板的 SoftAP 配网页和按键实现证据；专用铭牌解析/绑定后端尚未实现。ESP-IDF 骨架和现有 Gateway 不能据此宣称已具备这些功能。

## 后续经验记录格式

每项记录包含：问题与触发条件、适用型号/硬件修订、固件与 SDK 版本、官方资料链接、原因或设计依据、修复 commit、验证方法、真实观察结果、证据级别（需求/模拟/实物）、限制与未完成项。

没有观察结果的记录标为“规则/待验证”；实物测试通过后再补证据与适用范围。提交前移除 Wi-Fi 密码、token、私钥、个人对话、设备唯一序列号和私人网络标识；保留复现所需的板型与版本。不要将某块板的结论推广为所有固件通用。
