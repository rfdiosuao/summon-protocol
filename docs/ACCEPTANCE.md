## 契约层（当前可执行）

`python tools/validate_contract.py` 检查 Schema、正反 JSON 样例、场景关系与本地 Markdown 链接。结构通过不证明网络认证、数据库事务或物理停止实现正确。

## 端到端（实现后逐项）

| 检查 | 预期 |
|---|---|
| 同名注册/无 invite/错误 token | 409/401；不能冒名在线或驱动设备 |
| 正常注册→连接→召唤→双端 ready | registered 与 online 分开，双端就绪前不能执行 |
| 现场临时新输入 | 远端真实 Agent 决策，有关联 ID 与真实输出 |
| accepted 和 completed | 首者不能显示完成，后者须设备反馈 |
| 两人抢同一壳 | 仅一人成功，另一人 SHELL_BUSY |
| 断线/超时/急停 | 新动作停止，状态可见；不自动回放动作 |
| 旧 epoch/旧会话/过期动作 | 拒绝，不运动 |
| command_id 重复同内容 | 返回已有状态，执行次数仍为 1 |
| command_id 重复不同内容 | IDEMPOTENCY_CONFLICT |
| 网关在执行时重启 | UNKNOWN，核对设备，不自动重做 |
| Feedback 成功 | 事务提交后版本加一，换壳后应用偏好 |
| Feedback 冲突/存储失败/重复 | 不覆盖、不虚报成功、不重复加版本 |
| 跨操作者访问同一 Agent | 私人偏好隔离，不能读他人 session/memory |
| A→B 迁移 | A 停止确认后才 B 激活；旧端动作/写记忆拒绝 |
| A 无停止确认 | HANDOFF_BLOCKED，B 不获得控制权 |
| 目标在旧壳释放后失联 | handoff.failed，无自动恢复旧权限 |
| 快照→订阅期间发生事件 | 不漏事件；失效游标 reset 后重新同步 |
| 页面刷新/掉线 | 当前会话恢复正确，掉线立即禁控 |
| 回放/模拟模式 | 标记可见，不计入真实指标、不从回放发控制 |
| GLB/网页失败 | 不改变实际权限，DOM 操作可用 |
