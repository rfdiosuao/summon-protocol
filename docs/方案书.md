# 唤名 SUMMON 产品方案

2026-09-20 · v0.1.0 · 替代早期三机械壳/NFC 强依赖方案，工程以 [公共契约](PROTOCOL.md) 为准。

> Ghost 不住在这台机器里。它住在网络上。这台机器，只是它今天穿的衣服。

## 场景与价值

SUMMON 分离 Agent 身份、记忆和设备能力，让一个远端 Agent 在授权设备之间接续任务。当前是参赛参考协议，不能声称已成为行业标准。

首个验证场景为展会导览：手持设备上建立的讲解偏好，在展位设备上继续有效。准备 3 个核对过的展品资料与固定指示位置，找 3–5 位观众/工作人员验证换设备需要重复解释的问题。不预设复访率、节约时间、需求规模；登记数不能代替市场证据。

## 五个产品动作

| 名称 | 含义 |
|---|---|
| 注册 Register | 登记 Agent、取得 ID 和连接凭证，不等于上线 |
| 召唤 Summon | 授权操作者选择 Agent 和壳，申请会话 |
| 落地 Land | 双端确认后 Hub 发布 session.active |
| 交接 Handoff | 原壳停止、旧权限失效、记忆保存后，建立新会话 |
| 回流 Recall | 结果/反馈持久化；外部经验发布为独立异步扩展 |

五个故事动词不是完整 wire protocol。释放只结束会话；换壳包含释放和新建，字段与时序见公共契约。

## 身体与演示

入口、输出能力、心跳、本地停止、主人授权是壳的五项条件。屏幕和语音也是输出；运动设备需厂商独立急停。名字与被动 NFC 仅寻址，不认证。

两台 Passport 作为最低交付，一台手持、一台在展位。机械臂可用时与第二台组合，不把 Passport 绑在运动关节上。Agent 留在远端，不是复制两个聊天机器人。

在 A 上反馈“先用一句话解释”，等待保存；换到 B 后问新问题，观察偏好延续。星图显示控制权和记忆版本。有机械臂则调用有限、校准过的动作。停掉远端 Agent 后新的实时请求必须失败；缓存/回放显式标识。

## 视觉、生态与边界

保留深夜义体寄存处气质，星云中的真实节点与装饰粒子分开。先真实完成任务，再用视觉帮助理解。

只展示实际用过的赞助产品和作用，不推断“用了 Token 就拿高分”。未来可扩展门店、教育等，本次只验证展会场景。原生 App、通用硬件生态、自动双向记忆同步、Flipper、自由抓取不纳入。
