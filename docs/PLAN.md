# SUMMON 三人执行计划

2026-09-20 · v0.1.0 · 服务尚未实现；契约、样例与校验工具已入库。

## 1. 范围

**端到端最优先，星图并行。** 围绕跨设备展会导览，准备 3 个核对过的展品资料及固定位置映射，未知问题说明不知道。

| 等级 | 内容 |
|---|---|
| P0 | Hub、Agent 在线连接、两台 Passport、单会话控制权、真实显示/动作回执、记忆保存、状态官网与错误处理 |
| P1 | 已调通机械臂、第二个独立 Agent、一具 GLB、语音、NFC 固定接驳台（隔离性拉伸项） |
| P2 | 复杂粒子转场、外部经验回流、额外生态接入 |
| 不做 | 原生手机 App、自动多机双活、自由抓取、训练模型、通用模型编辑器、Flipper |

文字输入和屏幕输出可先验收。语音不阻塞主链，35 枚打印名牌与三具机械壳不再是最低交付。

NFC 接驳台是隔离性最好的拉伸项：只增一个 Gateway 输入源，不动 Hub 主链、不动 Passport 固件、不动前端。但 **P0 未绿前不许开工**，不得因为它体验好就抢先做。

## 2. 唯一责任人

| 人 | 主责（服务目录待建） | 交付/验收 |
|---|---|---|
| 队长 | `hub/`、`ghost_adapter/`、`protocol/`、部署 | 认证、目录、会话、工具调用、记忆、WSS/SSE；现场输入→远端决策→设备回执连通 |
| 设计师 | `web/`、`assets/`、路演物料 | 官网与星图、选择设备、输入/结果/错误面板；成功与失败都由真实事件驱动 |
| 小胖 | `firmware/`、`shell_gateway/`、`drivers/` | 官方 BSP、设备桥、动作适配、故障验收；按键输入、设备输出、回执和旧权限拒绝 |

小胖按“编译 BSP→屏幕显示→按键事件→连接网关→第二块板→可选机械臂”学习。卡点由队长短时结对，不同时承担视觉、语音算法和新运动规划。不是无边界的打下手。

前端用公共样例，设备用测试消息，后端用模拟壳，各自不等待。每半天合并可运行增量，每天至少一次三方联调。协议变更由队长协调，不能三端各自扩字段。

## 3. 工作前共同走读

用 60–90 分钟确认 [PROTOCOL](PROTOCOL.md) 和 [样例](../protocol/examples/README.md)。JSON Schema 跨 TS/Python/C++ 使用；后续 TS 类型从 Schema 生成，不要求固件使用 pnpm。

一个 Agent 一具壳；忙碌拒绝，不做排队抢占。Hub 签发租约并单点持久化记忆。字段改变同步更新 Schema/样例/文档。破坏性改变升级 wire 主版本，旧端必须明确拒绝。

## 4. 部署

服务器 A：Hub、SQLite、静态官网。服务器 B：可选语音桥与日志备份。远端电脑：Agent。现场电脑：Gateway 和厂商 SDK。8 核 8G 是轻量部署起点，容量需压测；星图在浏览器 GPU 渲染。

名字目录直接自建，未确认的 EvoMap 寻址接口不阻塞。外部经验回流是异步扩展，不是个人记忆的唯一存储。

## 5. 倒排

官方列出 9/21 20:00 开发启动、9/24 11:00 封板，中间约 63 小时，还需扣除休息和现场事务。赛前开发范围按官方规则确认并保留来源记录。

Day2 单板未通：队长与小胖结对，停止机械臂/NFC/特效。第二块板未稳定可展示单板+网页壳，但不得声称两台实物已交接。星图拖模型、复杂 shader 为可删项；WebGL 失败用 DOM 列表。

## 6. 验收与材料

[ACCEPTANCE](ACCEPTANCE.md) 是完成依据。“记住暗号”验证记忆；用户反馈改变换壳后回答验证偏好适应，不宣称模型训练。真实试用结果支持市场判断，不编参与人数或满意度。

四分钟：30 秒问题→45 秒 A 上交互/反馈→60 秒换壳新任务→45 秒状态/记忆证据→30 秒异常或外部接入→30 秒试用结果和范围。

仍需确认电脑系统/摆放位置、服务器网络、当前板卡固件、机械臂型号与完整配件、现有 Agent 框架、**NFC 读卡器能否自带**。资料核验不等于实物适配。
