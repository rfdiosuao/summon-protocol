> 把"任何 Agent 住进任何义体"从一份规格，变成**现场可当场验证、赛后可被第三方复现**的一套工程。

### 2.3 三条不变量（沿用文档红线，工程侧同样适用）

1. **刹车优先于一切**——物理急停不经过网络、不经过软件。
2. **机器主人的授权不可被绕过**——协议不提供"强制入住"能力。
3. **没有录音留存**——认人入口只认名字，不记事。


## 四、工作流 0：先定契约（阻塞其他一切）

**这是整个规划里最容易被跳过、但返工代价最高的一步。**

`packages/protocol` 用 TypeScript 定义五步消息流的 schema，星图、Shell、Ghost 三方共用同一份类型。

```ts
// packages/protocol/src/events.ts（草案）
type ProtocolEvent =
  | { t: 'REGISTER'; name: string; caps: string[]; at: number }
  | { t: 'SUMMON';   name: string; shellId: string; at: number }
  | { t: 'LAND';     name: string; shellId: string; latencyMs: number }
  | { t: 'HANDOFF';  name: string; shellId: string; at: number }
  | { t: 'RECALL';   name: string; shellId: string; recallId: string }
  | { t: 'SHELL_STATE'; shellId: string; idle: boolean; elements: ShellElements }

// 可入住五要素——一具壳的自我声明
interface ShellElements {
  identityGate: 'nfc' | 'qr' | 'button' | 'voice';
  actuator: string;     // 一只手
  heartbeat: boolean;   // 一颗心
  eStop: boolean;       // 一个刹车
  gate: 'whitelist' | 'open' | 'readonly'; // 一道门
}
```

**验收**：星图能只靠这份 schema 跑通一次完整五步（先接假数据源，再接真的）。schema 一旦定下，三方并行开发不再互相阻塞。
