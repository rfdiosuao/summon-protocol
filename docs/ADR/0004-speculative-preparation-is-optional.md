# 0004. 概率预判只用于可取消的准备工作

- 日期：2026-09-22
- 状态：Accepted
- 影响面：Gateway 可选扩展的设计边界；不修改 wire、Schema、Hub 或固件接口

## 背景

[条件反射层提案](https://feishu.doubao.com/docx/TtHCdJsCrobHnjxo0Cfcr7jEnrh) revision 4 建议用 Jev 预测召唤意图。将概率判断与确定性控制规则分开值得采纳，但提案依赖旧版常驻会话池、影子计划、NFC 场信号和眼镜设备，不能视为当前已有能力。

当前 Adapter 主动维持 WSS 连接；连接在线不代表持有执行会话。Gateway 没有预先读取访客记忆、替 Agent 建立身份连接或自行授予租约的权限。远端 Agent 的连接也不是 Gateway 本地能直接预热的资源。

## 决策

采纳模型中立的可选预判边界，Jev 仅为候选提供方，默认关闭。实现前先测量冷启动瓶颈、可用信号和确定性基线。无可预热资源或无净收益就不实现。

预测只允许准备 Gateway 自己拥有的非敏感、无执行副作用资源，例如加载驱动元数据或初始化纯软件编解码对象。不得初始化会导致电机使能、归零、播放或显示的驱动操作。

预判不得占壳、创建 session、续租、修改 enabled/ESTOP、读取个人 Memory、缓存或执行动作计划。用户明确操作仍走原有授权、offer/ready/activate 和动作校验路径；模型请求不得阻塞这条路径。概率输出不写 shell.report，不新增“影子命中”消息。

断网仍按现有停止规则处理，不回退到缓存动作。概率组件不持有 Hub/Gateway 身份凭证或设备句柄；由宿主通过固定白名单执行准备操作。任何晚到结果在状态改变后丢弃。

Jev 实验作为 P2；P0 双壳主线通过后才评估。Day3 12:00 前未证明可接入且优于确定性基线，关闭实验。本决策 Accepted 表示设计边界已采纳，不表示模型或 sidecar 已实现。

## 为什么不是另一个方案

| 替代方案 | 不采用的原因 |
|---|---|
| 全量采用原提案 | 影子动作与断网停止冲突；Gateway 无权预取私人记忆或代建 Agent 连接 |
| 先接云模型再找收益 | 已常驻连接时可能没有冷启动收益，反而增加网络、费用与调试负担 |
| 仅凭按键/NFC 事件预测 | 事件可能已经是明确召唤输入；直接处理比再分类更合适 |
| 完全禁止概率模型 | 非关键路径的资源准备允许实验，但须有实测收益和隔离 |

## 后果

不增加协议必需组件。需要额外测量、资源预算和关闭开关。参见 [实验规格](../REFLEX.md)；现有契约校验和设备自检不能替代未来 sidecar 的隔离测试。
