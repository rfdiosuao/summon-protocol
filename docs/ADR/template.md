# NNNN. 标题（一句陈述，不是问句）

- 日期：YYYY-MM-DD
- 状态：Proposed / Accepted / Superseded by `NNNN`（写编号，不要写链接，避免死链）
- 影响面：哪些文件或接口会因此改变

## 背景

当时面对什么问题。有哪些约束（时间、硬件、人力）是真的绕不过去的。

## 决策

我们决定做什么。用陈述句，写清楚边界——哪些情况适用，哪些不适用。

## 为什么不是另一个方案

列出认真考虑过的主要替代方案，以及否决理由。
**只写真正考虑过的**，不要为了丰满而编。

## 后果

这么做换来什么，付出什么。包括它让什么变得更容易、什么变得更难。

## 变更

后来改过的话记在这里：日期、改了什么、为什么。
