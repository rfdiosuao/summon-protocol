一具没有 Ghost 的 Shell，在现场等一个人

上一版我把硬件当成"可选装饰"，只做了个纯软件方案——这是根本性错误。这一版里，硬件是叙事的本体，EvoMap 是记忆的容器，而"招不到人的小队"这个种子，最终长成了赛事母题最正面的那个答案。

01

我上一版错在哪

诊断

赛事文档里明明给了一整套开发资源——机械臂、舵机驱动板、远场麦阵、触屏终端、外骨骼样机、3D 打印机——而我给的方案一件都没用，做了一个谁都能做的纯软件 Agent 工具。

更严重的是：赛道一的命题就叫「给 Ghost 一副身体」，赛道四叫「组建你的 Section 9」。这两个命题已经把答案写在题面上了，我却绕开去做了第三件事。

这一版的原则

  • 硬件必须是"非它不可"——拿掉这件硬件，故事就不成立。不是"顺便用了机械臂"。
  • EvoMap 必须是记忆本体——拿掉它，产品就不是产品，是一次性玩具。
  • 每件硬件都要有"抢不到"的降级方案——现场是要排队抢的。
  • 避开被做烂的套路——机械臂抓杯子、AI 聊天框套壳、多 Agent 写代码，一律不做。

03

主推：「义体」SHELL

赛道一 CYBERBODY（Seeed 出题）为主锚，EvoMap 为记忆本体。

一句话

一具没有 Ghost 的机械义体，低垂着头停在展台上。它在等一个愿意住进来的人。你住进去 40 秒，它替你完成一件事，然后记住你——下一个人来的时候，它已经带着你的经验。

赛道一命题是「给 Ghost 一副身体」。我们做的是它的反命题：先造一具身体，然后等一个 Ghost 住进来。而在《攻壳机动队》的语境里，"义体"（没有灵魂的义体）是整部作品最核心的意象——这是全场最正面回应母题的做法。

3.1 五步闭环（一轮约 40 秒，可无限循环）

01 · IDLE
义体
义体低垂着头，处于未激活姿态。大屏显示「空位 · 缺 1 名成员」。它在等人。
02 · 入住
你进来
你对着远场麦阵说一句话，或在触屏上按下入职键。你的身份被读取。
03 · 抬头
激活
义体抬起头、亮起——它现在有 Ghost 了。这是全场第一个哇时刻。
04 · 交付
替你做事
它带着你的身份去 EvoMap 检索前人经验，然后当面为你完成一件事（画一笔 / 写一个字 / 做一个手势）。
05 · 记住
留下痕迹
你的这次入住被结构化写进 EvoMap。屏幕：「义体记得你。」它回到待机——等下一个。

3.2 三个递进的哇时刻

时刻发生什么为什么打动人
① 低头的义体
任何时候走近都能看到		 一台机械臂垂着头，一动不动，屏幕上写着「缺 1 名成员」 不需要任何讲解，一眼就懂。而且它制造了一种"它在等"的情绪——这是纯软件做不到的。
② 抬头
你入职的那一刻		 义体从低垂姿态抬起，亮起，开始动 因为是你让它动起来的。评委亲手做的事带来的因果感，比看演示强十倍。
③ 它记得你
当天第二次路过时		 评委再走近，义体认出他：「欢迎回来。你上次让它画的那一笔，现在在教第 7 个人。」 这一条是为"30 位评委流动巡视"量身定做的——评委一天会路过你的摊位好几次。第二次被认出来，他会记得你一辈子。
为什么"义体"比"招不到人的小队"更有力

「招不到人的小队」是一个状态描述；而「一具没装 Ghost 的义体，一直在等一个人」是一个可以被看见的画面。同样一个意思，前者需要解释，后者只需要存在。
而且它顺手解决了你那个种子的情感内核：它招不到人，是因为那个位置一直留着——留给你。

3.3 评分维度对应

权重维度本方案给出的
60%Idea 核心概念：给"空位"一副身体。服务对象是现场的每一个人（评委自己就是用户）。痛点真实且即时的——不是虚构需求。技术门槛在：麦阵远场拾音与声源定位、姿态表达编排、身份的跨会话持久化、经验的结构化读写。差异化：全场唯一一个把"没有灵魂"做成了产品状态的作品。
20%UI 主视觉锚点 = 一条垂着头的机械臂 + 一个写着「缺 1 名成员」的屏幕。整个界面是一块"义体的仪表盘"：中央是它的姿态，周围环绕着曾经住过它的 Ghost 们（每个入住者一个小方块，累计叠加）。slogan：「它没有灵魂。直到你住进来。」
20%路演 利他三层都可直接落地，见 §3.6。最强的一点是：演示本身就是让评委当用户，不需要额外设计"即时体验"环节——他必须亲自住进来。

3.4 每件硬件的"非它不可"

硬件在故事里的角色拿不到怎么办
reBot Arm"义体"本体的第一候选。6+1 DOF 足够做出"低头 → 抬头 → 做一件事"的完整姿态叙事用总线舵机驱动板 + 拓竹打印自制一个非标头部/单臂装置（这也更原创，且呼应"尚未被定义的消费电子"）
远场麦阵"入住"的交互入口。嘈杂巡展现场隔数米说出你的身份，靠它才能做到；普通麦不行退化为触屏按键"入职"。闭环不变，只是少了"被听见"的魔法
reTerminal 触屏终端"义体的脸"——就挂在它胸前/旁边，显示姿态状态与 Ghost 名单用笔记本 + 外接屏替代，视觉稍差但可用
总线舵机驱动板降级方案的关键：让"非标准构型"成为可能，不必依赖成品臂—（它本身就是兜底）
Hypershell 外骨骼可选的第二形态：让"义体"也能被穿在身上（Ghost 进人，而不是人进壳）完全不用，不影响主闭环
拓竹 A1打印义体的外壳 / 结构件 / 给评委带走的小物件提前打印或手工替代

3.6 路演思路（因为演示即体验，路演只需要三句）

（指着那台垂着头的机械臂，不说话，停 2 秒）

「它不是坏的。它是一具空载的义体——没有 Ghost。」

「我们试过给它写一个灵魂，写不出来。所以换了个办法：让它等一个愿意住进来的人。」

「今天它已经被住过 XX 次。每一次，都留在了 EvoMap 里。所以现在的它，比早上那台更像个"人"。」

（把入职键推给评委）「你要试吗？40 秒。它会记住你。」

利他收尾（给评委能带走的东西）：「不管你今天住不住进去，这个思路你可以带走——做 AI 产品的时候，别急着给它一个灵魂。先给它一具身体，然后看谁会来。」

3.7 风险

风险兜底
抢不到 reBot Arm当天就要去排队占位；同时用总线舵机板 + 打印件做自制义体作为并行方案。自制版反而是加分项（更原创）。
"抬头"这个动作太简单，被质疑没技术含量动作不是核心，记忆闭环才是。把重心放在"它记得你"上：跨会话身份识别 + 经验继承。评审现场会问"你怎么知道是我"——这就是技术点。
被当成"机械臂表演"机械臂只是壳。把它降权：哪怕换成一个舵机做的转头装置，故事完全不变——证明壳不是重点。
40 秒一轮 × 几十人 → 现场排队与卡顿做并发队列：大屏同时显示多个 Ghost 在壳里的状态；降低单次时长到 25 秒。
EvoMap 写入失败 → "记得你"变成谎言本地镜像 + 写入重试；口播诚实说明「种子经验 + 真实写入」。绝不声称没做到的事。

05

怎么选：一个必须说清的战略问题

残酷提醒：只服务"现场这几百人"的作品，天花板到不了冠军

全场冠军的评语是「完成度、突破性、真实价值」，而评委席上坐着投资人（陈悦天）、硬科技创始人（潘昊）、云架构师（谭欣）。他们看到一个"只活 96 小时的活动工具"，会本能地判定没有市场。

但这不代表不能做。差别只在 framing：把现场几百人当成你的第一批真实用户和压力测试场，而不是产品本身。
路演里 70% 讲可泛化的内核（"义体"的内核是可持久身份 + 经验继承的具身交互终端，可卖给展厅、门店、博物馆、养老），30% 讲现场战绩（"今天它被 XX 个陌生人住过，零故障"）。
只讲现场 = 特别奖 / 人气奖。讲泛化 + 现场背书 = 有冠军相。

推荐打法

目标选什么为什么
主攻 「义体」，报 赛道一 CYBERBODY 硬件在赛道内是保供的（不用跟全赛道抢）；命题正面命中；游园会里"一台低头的机械臂"是所有摊位里最抓眼的静止画面；且演示即体验，7 分钟足够让每位评委亲手完成一轮。
副攻 观众选择奖 "它记得你"这件事对普通观众同样有效，而且每轮生成的入住凭证天然可拍照、可发小红书——观众奖和赛道冠军互相强化，不冲突。
白捡 小红书【小工具】奖 个人赛、独立评奖、截止早。派一个人两小时做掉。
建议放弃 评审团特别奖 / Token Maxxxing 特别奖要求"无法用单一指标定义"，主观性强、不可控；Token Maxxxing 是烧钱竞赛，会拖垮主队资源。别分散。

请确认：「运营参务表」是什么？

语音转写在这里不太清楚，我按字面猜了几个方向，但不想猜错方向浪费您时间。我目前的猜测是下面之一：

  • 任务 / 调度 / 排班表——给队伍分工、排岗、排作息、排硬件预约（我按这个做的那条 idea）

  • 其他——请给我一个词，我立刻重做这条方向

您只要回一句就行。其余六条方向不受影响，可以先看。
