# 固件配网、铭牌与返回交互要求

这是 SUMMON 自定义固件的产品要求，供生成或修改固件的 Agent 执行；不是现有模板已经实现的功能，也不是实物验收证据。开发前查明官方 BSP 的 SoftAP/STA、Web 服务、存储和按键接口；不得编造接口或默认所有联网芯片都支持热点。

## 1. 手机本地配网是 Wi-Fi 固件必交付项

- 有 Wi-Fi 且支持 SoftAP 的目标，首次启动、配置缺失或用户主动重新配网时，必须提供设备热点与手机可访问的本地配置页。热点名用 SUMMON-加短设备标识；提供每台设备独立的配网密码及可发现方式，不使用全产品共用默认密码。
- 用户流程：打开设备 → 手机连接设备 Wi-Fi → 打开本地页面 → 填写目标 Wi-Fi SSID、密码和 Agent 铭牌 → 保存并测试 → 显示联网和 Agent 连接结果。配置页自身不依赖互联网、云端登录、CDN 字体或脚本。提供明确的本地 IP 地址；自动弹出的门户只是辅助，不能替代手动访问地址。
- 配网入口在设备菜单或明确的本地操作中可再次进入；无屏设备通过标签、随附说明或语音说明热点名、密码获取方式及访问地址。必须在构建交付中写出真实入口，不能只说“进入配网模式”。
- SSID 支持手动填写；扫描为空仍可配置隐藏网络。密码遮挡并可切换显示。页面有返回、取消、保存/连接和明确状态提示，禁止空白转圈。移动端不用横向滚动即可操作。
- 提交先保存为待验证配置。验证成功再原子替换有效网络配置；密码错误、目标网络不可达或断电不能破坏上一份可用配置。网络配置与铭牌绑定状态分开保存，不能因铭牌离线而否定已成功的 Wi-Fi 连接。
- 若芯片无法 AP+STA 同时运行，明确告诉手机即将断开，提供重新接入方法；连接失败应在有界时间内恢复配网入口。交付中声明实际超时值与回退步骤，不承诺不存在的并发能力。
- 配网期间不开放远程动作。完成后关闭临时热点或按明确超时关闭；运行中短暂断网先按退避重连，不能直接打开无密码热点。重新配网先停止并释放控制会话；网络断开后的旧租约不能恢复执行。
- 本地保存密码与设备凭证，使用目标平台可用的受保护存储；页面不得回读已保存密码或 gateway token。配置提交采用 POST 和配网会话校验，不把密码放 URL、日志或云端经验。仅在本地配网模式允许更改网络和绑定目标。

仅支持以太网、BLE、蜂窝或 USB 的设备不能生成虚假的 Wi-Fi 热点功能。报告“不具备设备热点配网条件”，说明需增配兼容 Wi-Fi 硬件，或经用户认可使用手机/电脑 Gateway 提供等效本地配置入口；不能把替代方案标为满足原生 SoftAP 验收。

## 2. 铭牌配置与绑定

- 配置页必须提供 Agent 铭牌字段。铭牌是身份查询线索，不是控制密码、gateway token 或固定 URL；不得将任意输入拼成可访问地址。
- 分别展示：Wi-Fi 未配置 / 正在联网 / Wi-Fi 已连接 / 铭牌待解析 / Agent 离线或不存在 / 等待授权 / 已连接。Wi-Fi 连上不等于 Agent 已对接。
- 通过真实存在的 SUMMON 接口解析唯一 Agent 身份，显示名称和设备允许能力；设备主人确认授权后，以稳定 agent_id 建立有期限的会话。重名不能取第一项。铭牌公开也不能绕过设备授权。
- 截至本规则加入时，专用铭牌解析与绑定接口尚未实现。开发者必须先检查当前契约：缺少接口时可实现本地字段、保存和“待接入”状态，但必须明确标记未完成；先补齐后端契约、实现及测试，再宣称铭牌对接成功。禁止编造 /resolve 等接口，禁止把测试替身当生产功能。
- 更换铭牌时先释放旧会话并取得停止确认，再授权新 Agent。失败保留可理解的状态和返回入口，不让两个 Agent 同时控制同一设备。
- 页面展示经验上传声明：设备执行结果会上传配置的 SUMMON 云端，用于当前账号内的设备经验检索；不会因填写铭牌自动公开到全网。Wi-Fi 密码与 token 不属于经验上传内容。

## 3. 返回与确认键

- 每个非根页面都有明确返回入口；触屏页面必须有可点击返回。浏览器返回、设备返回操作和页面内返回保持一致。根页面返回保持在根页，不退出固件、不恢复出厂设置。
- 有确认键时，**双击确认键必须等价于返回上一级**。不能要求用户另找一个返回键。已有专用返回键仍可保留。
- 采用消抖后的释放事件判定双击，建议消抖 30ms、双击窗口 350ms；具体值随硬件测试调整并记录。第一次点击只进入待确认状态，窗口结束且无第二次点击时才执行一次确认；第二次点击在窗口内则取消待确认，只执行一次返回。
- 长按、自动重复与接触抖动不能当作双击。导航或模式改变时取消旧页面的待确认事件。计时使用非阻塞状态机，不能 sleep 阻塞网络、音频、看门狗或停止回调。
- 返回有未保存更改时可提供“放弃/继续编辑”；不得偷偷保存或提交。双击保存按钮对应的确认键不得先触发保存、配网、绑定、刷写或执行动作再返回。
- UI 返回是导航操作，不能替代机械急停。执行中页面需提供独立停止入口；若返回离开执行页面，应明确展示任务状态，不能让用户误以为导航已经停止设备。

## 4. 必须交付的验证记录

在独立的 firmware-ux 验收报告逐项记录目标板、源码版本、实际参数、操作、期望、观察结果和证据路径，状态为 PASS / FAIL / NOT_TESTED / NOT_APPLICABLE。不要擅自增加现有 admission-report JSON 的 schema 字段。

1. 首次上电，手机连设备热点，断开外网仍能打开本地配置页；自动门户不弹出时可用明确 IP 进入。
2. 正确 Wi-Fi、错误密码、隐藏 SSID、路由器不可达；错误可重试，旧配置不丢失，手机有返回/恢复路径。
3. 保存中断电、重启、主动重新配网；凭证不出现在 URL、日志、回读页面和经验上报。
4. 有效铭牌、不存在铭牌、Agent 离线、未授权、切换 Agent；分别核验网络状态与会话状态，不使用模拟解析冒充通过。
5. 每个非根页的返回、根页返回、未保存表单返回；单击只确认一次，窗口内双击只返回一次，跨窗口两次点击按当前页面规则处理。
6. 按键抖动、长按、连续点击、页面切换时仍有待确认计时器；不能产生多次动作或落到新页面误确认。
7. 进入配网及更换 Agent 时先停止旧会话；断网后无旧动作重放。独立验证云端经验入库，不把 Wi-Fi 配置成功当作上传成功。

没有实物时，可提交状态机和模拟测试结果，但上述手机配网、真实按键及真实绑定必须保持 NOT_TESTED。这些要求不能靠编译成功替代。
